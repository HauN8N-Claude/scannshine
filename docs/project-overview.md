# ScanNShine ⭐

**Transformez vos clients satisfaits en avis Google — pensé pour les commerces du fenua.**

SaaS pour les TPE de Polynésie française : un QR code permanent (chevalet en caisse, autocollant, ou affiché depuis le smartphone du gérant) envoie chaque client vers une page de collecte aux couleurs du commerce, puis vers la fiche Google Business. Les clients insatisfaits sont captés en privé — sans jamais masquer l'accès à Google (conformité politique UGC).

- **Cible** : restaurants, snacks, roulottes, salons, garages, artisans, pensions, activités touristiques
- **Modèle** : abonnement self-service 3 990 XPF/mois (~33,50 €), essai 7 jours
- **Stack** : Next.js 16 (NOW.TS) · Prisma + Neon · Better-Auth · Dodo Payments · Resend · Vercel
